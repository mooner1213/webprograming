# 웹 프로그래밍 결과물

웹 프로그래밍 결과물을 정적 파일 형태로 보관하는 저장소입니다. 현재 구성은 HTML 진입점과 빌드된 JavaScript·CSS 및 이미지 리소스 중심입니다.

## 구성

| 경로 | 역할 |
| --- | --- |
| [index.html](index.html) | 페이지 진입점 |
| [static](static) | 빌드된 스크립트와 스타일 |
| [assets](assets) | 이미지·스타일·라이브러리 리소스 |
| [asset-manifest.json](asset-manifest.json) | 빌드 자산 정보 |
| [CNAME](CNAME) | 사용자 도메인 설정 파일 |

## 확인 방법

저장소 루트를 정적 웹 서버로 제공해 페이지를 확인합니다. 현재 루트에는 원본 개발 프로젝트의 `package.json`과 `src` 구조가 없어 `npm install`과 `npm start`를 실행하는 방법은 제공하지 않습니다.

사용된 외부 라이브러리와 템플릿은 각 제공자의 리소스입니다. 개발 기여는 원본 소스와 작업 범위가 확인되는 항목을 기준으로 설명해야 합니다.
